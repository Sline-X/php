Разница между localStorage и sessionStorage заключается во времени хранения данных: 2

LocalStorage позволяет хранить данные без срока действия. 1 Они не будут удалены после закрытия браузера и останутся доступными при следующем открытии веб-сайта. 1 LocalStorage подходит для хранения данных, которые необходимо сохранить на длительный срок, например, информации о предпочтениях пользователя. 1
SessionStorage хранит данные только в рамках одной сессии, то есть до тех пор, пока открыт браузер. 2 После закрытия браузера данные удаляются. 14 Это делает sessionStorage идеальным для хранения данных, которые актуальны только в рамках одной сессии, например, данные формы, которую пользователь заполняет. 1
Таким образом, localStorage используется для долгосрочного хранения данных, а sessionStorage — для временного, в рамках одной сессии.
